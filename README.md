## 🚀 Quick Start

```r
# Install packages (first time only)
install.packages(c("TSA", "forecast", "tseries"))

# Load them
library(TSA)
library(forecast)
library(tseries)
```

Then open the R script inside any TD folder (e.g. `TD1/`) in RStudio and run it.
